Epub Binder 사용 설명서

EPUB 병합, 이름 변경, TXT 변환, 중복 정리를 한 프로그램에서 처리합니다.

병합

  1. 파일 열기로 합칠 EPUB을 선택합니다. 새 파일을 다시 추가하면 기존 병합 목록은 새 목록으로 교체됩니다.
  2. 자동 정렬은 본편을 먼저 두고, 에필로그, 외전, 특별외전 순서로 뒤에 배치합니다.
  3. 파일명은 단행본 묶음이면 전체 파일 수 기준으로 1-n권 형식이 됩니다. 예를 들어 본편 8권, 외전 2권, 특별외전 1권이면 1-11권 (완결)로 잡습니다.
  4. 목차에서 권 제목과 화 제목을 확인하고 필요한 부분만 수정합니다.
  5. 병합 시작을 누르면 완료 후 파일 목록이 자동으로 비워져 같은 목록을 실수로 다시 병합하지 않습니다.

표지

선택 버튼을 누르면 전체 병합 목록에서 표지 후보를 모아 보여줍니다. 라디오 버튼으로 대표 표지를 1개 고르고, 표지 추가를 체크하면 대표 표지 뒤에 추가 표지가 순서대로 들어갑니다.

EPUB 내부의 모든 이미지 표시는 표지 후보가 부족할 때만 켜면 됩니다. 삽화도 함께 보이므로 필요한 이미지만 확인해서 선택합니다.

이름 변경

  1. 열기로 파일을 불러오면 변경될 이름을 미리 보여줍니다.
  2. 외전, 번외, 특별외전은 같은 작품 묶음으로 인식합니다.
  3. ZIP 묶기는 변경된 이름 기준으로 같은 작품끼리 묶습니다. 원본 파일명보다 정리된 파일명을 기준으로 묶고 싶을 때 사용합니다.
  4. 1-1권, 1-2권, 상/중/하처럼 서로 다른 권차 표기는 정상 파일로 보고 보존합니다.

TXT 변환

TXT를 EPUB으로 만들 때 표지를 지정할 수 있습니다. 네이버 시리즈 표지를 직접 가져와야 할 때만 오른쪽 위 설정에서 쿠키를 저장합니다.

시리즈 표지 쿠키

  1. 브라우저에서 네이버 시리즈에 로그인합니다.
  2. 작품 페이지에서 개발자 도구를 열고 Application 또는 저장소 탭으로 이동합니다.
  3. Cookies 항목에서 NID_AUT, NID_SES 값을 복사해 프로그램 설정에 붙여넣습니다.

중복 정리

  1. 정리할 폴더를 선택하고 스캔합니다.
  2. 삭제후보 자동선택을 누르면 안전한 후보만 체크됩니다.
  3. 확인 필요 항목은 확인대상 해시 확인으로 내용을 비교한 뒤 판단합니다.
  4. 선택 항목 격리 폴더로 이동을 누르면 파일은 삭제되지 않고 선택한 폴더 안의 _dedupe_trash_날짜 폴더로 이동합니다.
  5. 문제가 있으면 최근 격리 복구로 되돌릴 수 있습니다.
