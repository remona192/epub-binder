# 파일 관리자 (Android)

삼성 '내 파일'처럼 단순한 UI의 안드로이드 파일 관리자. Kotlin + Jetpack Compose, minSdk 26 (Android 8.0+).

## 기능

| 요구사항 | 구현 |
|---|---|
| 복사·이동·삭제 (삼성 내 파일 방식) | 길게 눌러 선택 → 하단 바 `이동/복사/이름 변경/삭제/더보기`. 이동/복사를 누르면 폴더를 찾아가 `여기로 이동/여기에 복사`. 같은 이름이 있으면 `건너뛰기 / 이름 변경(둘 다 유지) / 바꾸기` + "남은 항목에 모두 적용". 폴더끼리 바꾸기는 병합. 같은 폴더에 복사하면 `이름 (1)` 사본. 삭제는 휴지통(30일 보관, 복원 가능), 설정에서 끌 수 있음 |
| 휴대폰 저장공간 전체 검색 | 내장 메모리 + SD 카드 전체를 색인해 즉시 검색. 부분 일치(`내가` → `내가 잘못했다면`), 단어 순서 무관, 공백 무시(`내가잘못`), 초성(`ㄴㄱ`), 대소문자·NFD 한글 파일명 대응 |
| 원하는 뷰어로 고정해서 열기 | 처음 열 때 앱 목록에서 `항상` → 그 확장자는 다음부터 묻지 않고 바로 열림. 바꾸기: 파일 길게 누르기 › 더보기 › 다른 앱으로 열기, 또는 홈 › 기본 앱 설정에서 변경/해제 |
| 배치 네이머/이지네이머식 일괄 이름 변경 | 여러 파일 선택 › 일괄 이름 변경. 규칙(찾아 바꾸기·**정규식**·`$1` 그룹, 글자 넣기, 글자 지우기, 번호 붙이기, 이름 틀 `{name} {n:3} {parent} {date}`, 대소문자, 확장자)을 순서대로 쌓고 실시간 미리보기, 충돌 검사, 적용 후 `실행 취소` |
| 파일명 일치율 90% 이상 중복 찾기 | 홈 › 중복 파일 찾기 (또는 폴더 › 더보기 › 이 폴더에서 중복 찾기). 일치율 = 1 − 편집거리/긴 이름 길이. 기준 60~100% 조절, 같은 확장자끼리만, 숫자(1권/2권)가 다르면 제외, 사본 표기 무시 옵션. 그룹별 "최신 1개만 남기고 선택" 후 삭제 |

## 구조

- `core/` — 안드로이드 의존 없는 순수 Kotlin 로직 + JUnit 테스트 (검색, 복사/이동, 휴지통, 일괄 이름 변경, 중복 찾기, 정렬)
- `app/` — Compose UI, 저장소 색인, 기본 앱/파일 열기

## 빌드

```bash
./gradlew :core:test            # 로직 테스트
./gradlew :app:assembleRelease  # app/build/outputs/apk/release/app-release.apk
```

`app/sideload.keystore`는 덮어쓰기 설치가 되도록 고정한 **사이드로드 전용** 서명키다 (Play 스토어용 아님).
GitHub Actions(`.github/workflows/file-manager-apk.yml`)도 같은 APK를 빌드해 아티팩트로 올린다.

## 설치 후

처음 실행 시 **모든 파일 관리 허용** 권한을 켜야 한다 (Android 11+). 전체 저장공간 검색·복사·이동에 필요하다.
